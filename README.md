# 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma **plataforma digital fictícia voltada para impacto social**, criada para **divulgar projetos sociais e conectar voluntários, organizações e apoiadores**.

A aplicação foi desenvolvida utilizando **React** com uma arquitetura baseada em **componentes reutilizáveis**, priorizando:

- experiência moderna
- design acessível
- organização de código
- responsividade
- boas práticas de desenvolvimento frontend

A plataforma tem como objetivo **inspirar engajamento social e facilitar conexões entre pessoas que desejam gerar impacto positivo na sociedade**.

---

# 🌍 Contexto do Projeto

A plataforma tem como objetivos principais:

✔ Dar visibilidade a projetos sociais  
✔ Apresentar informações claras e acessíveis  
✔ Inspirar engajamento e transformação social  
✔ Conectar voluntários, organizações e apoiadores  
✔ Transmitir confiança, empatia e profissionalismo através do design

# ⚙️ Funcionalidades da Plataforma

A aplicação possui diferentes páginas voltadas para interação com iniciativas sociais.

Entre as principais funcionalidades estão:

✔ Apresentação da plataforma e projetos sociais  
✔ Página dedicada para **doações**  
✔ Página para **voluntariado** em projetos sociais  
✔ Página de **mentorias** para compartilhar conhecimento  
✔ Página de **eventos e palestras**  
✔ Página de **perfil do usuário**

---

# 🌐 Rotas da Aplicação

A navegação da aplicação foi implementada utilizando **React Router DOM**.

| Rota | Página | Descrição |
|-----|-----|-----|
| `/` | Página Inicial | Apresentação da plataforma e projetos sociais |
| `/Doacao` | Doação | Página para apoiar projetos com doações |
| `/Voluntariado` | Voluntariado | Página para escolher projetos para ajudar |
| `/Mentoria` | Mentoria | Página para oferecer ou receber mentorias |
| `/Eventos` | Eventos e Palestras | Divulgação de eventos sociais |
| `/Usuario` | Perfil do Usuário | Página de perfil do usuário |

# 📱 Responsividade

A aplicação foi desenvolvida com foco em **responsividade**, garantindo uma boa experiência em diferentes dispositivos.

Foram utilizadas técnicas como:

- unidades relativas (`%`, `rem`, `vh`, `vw`)
- `max-width`
- **media queries**

A interface adapta-se para:

- desktop
- tablets
- dispositivos móveis
